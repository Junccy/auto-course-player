# auto-course-player
专门针对于武汉理工大学的小雅平台——理工智课——自动完成视频和文档这一类的自我观看。后续如果有时间的话，可能会考虑加入答题功能。

# 准备
建议在Chrome中运行，需要配备篡改猴插件(Tampermonkey)&emsp;&emsp;URL:https://github.com/Tampermonkey/tampermonkey

**记得在篡改猴里面将允许运行脚本打开**

将“理工智课1.1.user.js”文件中的代码完整复制下来，粘贴于篡改猴中的新建的脚本，保存，打开脚本的运行开关即可。

# 功能

<img width="343" height="363" src="https://github.com/user-attachments/assets/559ba483-53ba-48c2-91a0-b866852469c2" />

- 文档类自主观看，可以修改并发的标签页面数量（一次性打开多少个任务），然后会出现倒计时，等待即可。
- 视频类自主观看，可以先尝试打开“优先验证底层进度写入”（可以直接修改小雅的右上角完成进度，相当于几秒钟完成一个视频）；若出现问题（我目前还没遇到），可以尝试关闭该功能，那么视频将会以16倍速播放。视频播放会自动静音。
- 当点击了“开始”按钮后，就不要再点击脚本自动打开的标签页了，所需要做的就是等。你可以将浏览器窗口置于其他应用的后面，至于最小化还能不能继续刷，我还没有验证。
- 需要暂停，就点击“暂停”。在刷视频的标签页中没有该选项，需要退回到作业任务的标签页点击。

# 使用方法

<img width="600" height="400" src="https://github.com/user-attachments/assets/c07de384-e206-4fbe-a0d5-9ff5bf23e6f4" />

手动进入需要刷课的课程，进入如上的“作业任务”界面，推荐将“仅关注待完成任务”选项打开（虽然不开问题也不大，但可以缩短脚本循环的时间）。

右下角应该会自动出现脚本窗口，如果未出现，检查该脚本是否开启、篡改猴中脚本功能是否开启，开启后，刷新页面即可。

点击“开始”就OK了！
